# UI/UX Brief - KOSHAI v0.2

## 1. Visual Identity
- **Primary Color:** `#DA291C` (Red - symbolizing the theme).
- **Secondary Colors:** `#228848` (Green - Success), `#C49A26` (Gold - Charity/Premium).
- **Typography:** **Hind Siliguri** (Primary font for Bengali text).
- **Logo:** Programmatic React SVG (Zero-weight, scalable).

## 2. Design Principles
- **Premium Feel:** High-quality shadows (`box-shadow: 0 4px 14px rgba(218, 41, 28, 0.35)`), rounded corners (12px - 16px), and smooth transitions.
- **Consumer Psychology:** Warm, trustworthy colors; familiar icons (🌙, 🐄, 🪔); and clear Bengali calls to action.
- **Mobile-First:** Full-width buttons on mobile, touch-friendly targets, and PWA optimization.

## 3. Component Standards

### 3.1 Buttons
- **Primary:** Red background, white text, bold, with active scaling (0.97).
- **Secondary:** White background, red border, premium hover state.
- **Ghost:** Minimalist text buttons for secondary actions.

### 3.2 Cards
- **Standard:** White background, subtle border (`#F5EFE8`), and soft shadow.
- **Skeleton:** Shimmering loading states for data fetching.

### 3.3 Layout
- **Spacing:** 16px horizontal padding for all screens.
- **Banners:** Full-width gradient banners for charity and special alerts.

## 4. Specific UI Enhancements
- **Eid Countdown:** Prominent gradient widget with pulsing numbers.
- **Stats Bar:** Pill-shaped badges showing live counts from Supabase.
- **Charity Banner:** Warm gold strip at the bottom of the Home screen.
